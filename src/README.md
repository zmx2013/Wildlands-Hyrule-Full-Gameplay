# Wildlands source

- `kubejs/` contains gameplay source for registration, durability, combat, runes and world progression.
- `datapack/` contains load/tick functions and deterministic Blood Moon camp-reset logic.
- `config/` contains source configuration presets.

Generated structure binaries are kept in release artifacts; v2.0.0 contains 120 shrines, 15 towers, 900 puzzles, 4 dungeons and 32 camps (1071 NBT files total).
