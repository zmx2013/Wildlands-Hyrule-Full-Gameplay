# Contributing to Wildlands

## Development

1. Fork the repository.
2. Create a feature branch.
3. Test KubeJS syntax before submitting changes.
4. Include a clear description of gameplay impact.

## Code style

- Keep KubeJS systems separated by responsibility.
- Prefer deterministic server-side state over client-only effects.
- Document new datapack functions.

## Pull requests

Good PRs include:

- What changed
- Why it improves gameplay
- How it was tested
- Any compatibility considerations
